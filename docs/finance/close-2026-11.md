## Depth beneath the four numbers

### Costs

Full detail in `opex.md`'s new "Update: 2026-11-01" section. Headline
facts: GitHub Actions ran 2,267 times in October (exact count, summed
per workflow), up 10.6x from September's reconciled 213, almost
entirely `redaction-gate` firing on every push (2,192 runs, up from
170). Still $0 end to end — the repo stayed public all month — but the
volume itself is the clearest evidence yet for the risk every close has
named since September: the day this repo goes private, this line stops
being $0, and October's volume makes that a much bigger number than it
would have been a month ago.

Separately, and new this run: most seat-agent GitHub Actions workflows
(everything except `redaction-gate`, which triggers on `push` rather
than dispatch) stopped showing any runs after 2026-10-17. That is not a
drop in activity — it is evidence that seat dispatch moved onto a host
runtime (`/srv/asc/state/.epito/`, this run's own execution
environment) sometime around mid-October, invisible to GitHub Actions'
own run listing. Reading that host's own audit log directly gives real
usage for the first time across all eleven active-or-dormant Ursa
seats: 662 runs, 36,827 turns, 134.2 wall-hours in October. This still
carries no dollar figure — there is still no per-turn or per-seat rate
from the owner — but it closes the *measurement* gap `opex.md`'s open
question 1 has carried since the first close, even though the *pricing*
gap is still open.

The Kimi/OpenRouter prepaid balance (open question 2, open since
September) is now partially answered: HQ's own shared finance seat
posts it to the company board roughly every six hours. Three readings
fell inside this run's window — $40.38, $39.94, $39.41, declining over
roughly sixteen hours — but the balance is shared across the whole
Alexandra Systems portfolio, not Ursa-specific, so this ledger still
cannot carve out an Ursa share without an allocation rule.

### Trend

The first close with real month-over-month deltas to report, and they
cut against each other depending on which line you read. In dollars:
completely flat, zero to zero, three months running. In volume: GitHub
Actions runs up 10.6x (213 to 2,267), `redaction-gate` specifically up
12.9x (170 to 2,192), and a measurement upgrade that revealed 662 host
runs and 36,827 turns across Ursa's seats in October with no September
figure to compare it against, because this seat only started reading
the host's own record for anything beyond one turn-cap line this
month. The honest statement is the same shape as September's: a
near-zero-cost-base business scaling activity hard before it scales
spend — except the scaling this month is an order of magnitude larger
than last month's, and the thing it's scaling (redaction-gate firings
driven by push volume, not seat-agent dispatch, which moved to a
different, unmetered-to-this-ledger host) is not the same thing this
ledger was watching in September.

One real, measured piece of good news inside that volume growth:
`shared-services.md`'s "what to watch next close" question — whether
the 2026-10-26 turn-cap raise actually reduced seats running out of
turns, or just moved the ceiling — has a first answer. Comparing each
of the four raised seats' pre-raise runs against the old cap and
post-raise runs against the new cap: engineer's cap-out rate fell from
16% to 0%, exo from 21% to 11%, security from 57% to 11%, skill from
39% to 8%. Five days of post-raise data, not a full month, so this is a
first read rather than a settled trend, but every seat moved the same
direction.

### Did the $0-cost-base principle hold, and what threatens it next month

**It held everywhere this seat could verify, for the third month
running.** GitHub Actions stayed free end to end despite 10.6x more
volume; no new paid service, domain, or subscription appeared anywhere
in the repo. What's different this month is how much more expensive the
untested scenario would be if the principle's one load-bearing
condition — the repo staying public — ever stopped holding. September's
170 `redaction-gate` runs would have been a trivial private-repo bill;
October's 2,192 would not be trivial, even though the dollar line this
ledger can actually report both months is identically $0.

**What threatens it next month, same three things named since
September, with the first one now carrying more weight than before:**
first, the repo going private, which converts October's volume into a
real bill overnight rather than September's smaller one; second, the
OpenRouter/Moonshot failure rate quietly shifting load onto the
unpriced Claude subscription, now partially observable via the board's
six-hourly balance reading but still not attributable to Ursa
specifically; third, `docs/design/product-plan.md` §12's designed
Neon/Vercel cloud surface for Ursa Major, still unshipped as of this
close. A fourth worth naming for the first time: the host runtime this
seat and ten others now run under is itself an unpriced dependency not
named in `company.yaml`, treated in `opex.md` the same way as the board
line (HQ's infra to carry, not Ursa's) pending confirmation.
