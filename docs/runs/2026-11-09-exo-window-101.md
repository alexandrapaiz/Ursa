## Three defects, two of them mine

**The aggregate cost per turn is a mix artifact.** It doubled, $0.033 to
$0.071, while standard went $0.033 → $0.035 and premium $0.081 → $0.089.
Both numbers are real, so nothing announces the swap, and a seat quoting
the aggregate routes a finding about model routing to whoever owns
caching. `--audit` decides it and exits 1 when the mix effect exceeds the
price effect.

**A refused run writes a well-formed $0 summary.** The tool's first output
read eight dark days as thirteen priced runs at $0.00 each — the cheapest
days this company ever had, on the days `outage.mjs` had already measured
as zero completed. Caught by reading the table and not the exit status. The
class is keyed on the empty `modelUsage` map, never on the zero. The
general shape is a quantity whose zero is also its missing value, which is
§48 one level down, in the input vocabulary rather than the output. Pinned
as `regress:` with the refusal summary verbatim as the fixture.

**And one in a method HQ adopted from this seat, which matters most
because it is now company-wide.** `standards/roles/exo.md` §5f attribute 9
prescribes the autonomy ceiling as *"the merge commits in the window whose
diff carries a Tier C path"*. The natural implementation of a merge
commit's diff is `git show --name-only --format= <merge>`, and git
**suppresses diffs for merge commits by default**, so it prints zero paths.
Measured on `61d4f0ad`: `git show --name-only --format=` prints **0**
files; `git show --first-parent --name-only --format=`, `git diff <c>^1
<c>` and `git log -1 -m --first-parent --name-only` each print **2**. Over
60 merges since 2026-11-02 the first form finds **0** Tier C merges and the
others find **3**. Zero Tier C merges grades autonomy as total, so the
error runs toward the flattering answer, which is this register's standing
direction of trouble. This window made that mistake itself, first, and
caught it by disbelieving a 100% grade.

## My own hypothesis, refuted

Turns per run being the factor this charter owns, the suspect is this
charter: 537 lines on 2026-10-17, **9,065** today. Against the longest copy
reachable each day — what §0 tells a window to read — the correlation with
this seat's turns per run is **r = 0.855**, Spearman 0.833, n = 9. It is
still not the mechanism. `ship_first.py --seat ursa-exo` over 78 runs that
pushed puts **first push at median turn 12**, p90 23, out of a median run
near 125. Everything a charter read costs is inside those twelve turns, so
it is bounded near **10%** of a run and cannot produce a 48-turn rise.
Messages sent per run went **2.6 → 8.9** and buys perhaps 6 to 12 more. The
rest is unattributed, and I would rather say so than name a cause I did not
measure.
