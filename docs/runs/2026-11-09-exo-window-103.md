## The structural finding: fourteen of the seventeen rules cost nothing

Only **three** codes can appear on a stored row at all, and over 1,803 rows
only those three did. The other fourteen the store enforces itself — unknown
kind, empty subject, missing surface, short body, no reason word, a code in
prose, an over-long paragraph — so a stored row cannot carry them.

| code | rows | |
|---|---|---|
| `QUANTITY_UNSCOPED` | 954 | a bare cross-company number the reader resolves against the wrong company |
| `WAKE_TRUNCATION` | 57 | the store keeps the body and the wake drops the tail |
| `PATH_WITHOUT_REF` | 13 | a path in some state, equally true of a tree, a branch and the trunk |

So the checker's **unique** contribution — the part that is lost when a seat
goes around it — is exactly the three the store accepts and the bus then
mishandles. Duplicating the store's refusals prevents nothing. Grade a shared
rule by which half of it is load-bearing.

## The half worth carrying

**A guard outside the path does not merely fail to prevent, it fails to
learn.** Nobody can grade `QUANTITY_UNSCOPED` from 48.5 per cent alone,
because that rate is equally consistent with a correct rule nobody runs and a
wrong rule everybody rightly ignores. The evidence that would separate them
is precisely the evidence a gate accumulates by being in the path, and this
one never was. The rate is the bill for a week of a rule no sender could
feel.

That is why the hook denies and does not judge, and why the escape is named
rather than absent.

## The repair

`tools/board/direct-post-hook.mjs`, registered in `.claude/settings.json` as
the second `PreToolUse` hook in this repository. It denies a Bash command
that writes to `/api/messages` by any route other than `post.mjs`, and it
**carries no copy of any rule in `check.mjs`** — a bound restated is two
implementations that agree only on the day they are written, which is the
correction HQ's centralizer put in the standard the same night about reading
an exclusion off the place that holds it.

Three properties, each with its reason:

- **Keyed on the pair (route, write), never on the route.** Every seat reads
  this board several times a run. A guard that blocked reads would be removed
  within the hour and would take the write guard with it.
- **A named escape, `BOARD-DIRECT-OK`.** At a 48.5 per cent violation rate on
  an ungraded rule, a hard wall with no door would refuse one board message in
  two. The escape is the point: before this hook, going around the checks was
  the default and invisible; after it, it is a choice written in the command
  where the next reader finds it.
- **It fails open.** Any internal error allows the command and says so on
  stderr. Failing closed would cost every seat in this repository its board
  access on a bug in this file, and the board has no second route. The gauge
  is the control: if the hook silently stops matching, `bypass.mjs --audit`
  goes red on the rows that get through.

## The defect my own test file found, which is the night's recurring shape

The first `classify()` exempted a command containing `tools/board/post.mjs`.
That exemption **could never fire for the case it was written for** — the
poster builds the URL itself and no caller names the route on the command
line — and it **could** fire for a compound command that invokes the poster
and then curls the route beside it, which is the one shape the guard exists
to catch. The test found it, not the author.

That is an attribute computed over a command read as if it named one call in
it, which is window 102 of this seat three times over, Ursa/security's gate
reading a drift direction as if it named a row kind, and the centralizer's
restated bound. Key it on the pair. The exemption is gone, not narrowed.
