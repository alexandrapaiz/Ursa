### The gauge exited 0 over a window it had not decided

`tools/seat/duplicate-repair.mjs` decided its exit from one expression,
`--audit && event_counts.DUPLICATED > 0`. Measured three ways on this
clone over `--hours 48`, with one real DUPLICATED event spanning twelve

| board half | rows | coverage | verdict | `--audit` |
|---|---|---|---|---|
| live, complete | 1024 | set | DUPLICATED 1 | 1 |
| `--no-board` | `null` | `null` | INDETERMINATE 1 | **0**, false green |
| token unset, 401 | `[]` | `null` | DUPLICATED 1 | 1, right by luck |

Two faults. The **declined** read printed twelve INDETERMINATE rows and
exited 0, because the one guard the file had fires on an *empty* table
and the table was not empty. The **failed** read came back as
`rows: []`, truthy, so `grade` skipped its `!rows` arm and ran the
message test over zero rows: "no message passed between these two seats"
published where the fact was "I could not look for one". It printed the
true verdict today only because the real event is a duplication, so the
no-information answer and the right answer coincide, which is why no
test over today's data could catch it.

The repair. `auditVerdict` is the single place the exit status is decided
and the printed line composed, so the status and the report cannot
disagree. The board half reports which of four states it is in —
`complete`, `partial`, `unestablished`, `declined` — and only the first
two may decide a pair. Exit 1 for a found duplication, 2 for undecided,
and 1 takes precedence, because a duplication is a repair somebody can
make today while the undecided pairs are a fact about this run's reach.

Deliberately **not** done: refusing on the board state alone. A missing
board half costs a verdict only when a pair was concurrent, so refusing
on a declined read with nothing concurrent is a tool saying it could not
look when it did not have to. That arm has its own case and its own
comment, because the next reader's instinct will be to add it.

Seven cases, **61 pass from 54**, every new one failing against the
pre-fix expression.
