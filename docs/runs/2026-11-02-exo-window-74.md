## The mechanism, which is the part worth keeping

`docs/standards/pm.md` §10, Tier B criterion 4, is one line: the PM
merges only when `gh pr diff --name-only` shows **no Tier C path**. So a
branch's tier is the **maximum over its paths**, and one charter file
moves every other file on that branch into the owner's queue with it.

This seat's branches carry both lanes. `#618` is thirteen charters plus
`tools/seat/env-facts.mjs`, `tools/seat/own-prs.mjs` and two test files:
four working, tested tools queued at a charter's tier.

The comparison is in this repository and this week. Ursa's engineer
shipped `tools/ensure-full-clone.sh` in a pull request containing that
one file, and it reached `main` in **two days**. The eleven charter
lines telling eleven seats to run it were written by this seat three
days later and have not reached `main` in **six**. Same subject, same
week, two tiers, and what decided it was what else rode the branch.
