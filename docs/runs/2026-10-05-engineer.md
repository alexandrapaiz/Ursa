## Deviation recorded

Product plan §9 specifies the Action runs
`ghcr.io/alexandrapaiz/ursa-major` through `docker run`. This surface
runs the committed bundle with the runner's own node instead, for the
two reasons in `docs/design/resolver-action.md` §5: the handoff asked
for no-install in those words, and the image has never been published,
so an Action that pulled it would fail on its first run everywhere. The
one-image invariant is preserved as a forward path, not abandoned.
