## The instrument: `tools/board/route-reach.mjs`

Two sweeps already grade what a charter names and neither can see a route.
`tools/seat/tool-reach.mjs` grades tool **paths**, in five states against a
discovered root set. `tools/board/read-filters.mjs` grades **filter
parameters**, on the three routes it declares. Nothing has ever asked whether
a board route a charter tells a seat to call resolves at all, and §7280's own
standing rule — *never re-derive this list, ask the route for it* — was
written about the filters and has no counterpart for the path.

**The sweep is green from birth.** 75 distinct (path, method) calls, 12 route
names, 165 citations; every route a charter or standard binds a seat to call
resolves. The value is in the four traps it took to be able to say that, and
three of the four this tool committed against itself before it shipped.

| trap | the false reading | the fix |
|---|---|---|
| 1. bare-prefix probe | called 4 of 11 routes absent; all four false, they are written as sub-paths | probe the citation, never a name derived from it |
| 2. keyed on HTTP status | `/api/health` answers **503** because this host is at 97%; a present route saying the most urgent thing the board can say, graded missing | grade on the board's own vocabulary |
| 3. marker as a bare substring | called `/api/agents` absent; it answers 200 with **573,978 bytes** of agent prompts, which are this repository's charters, one of which documents `{"error": "no such route"}` verbatim | ABSENT is the pair: 404 **and** `error` exactly the marker |
| 4. method unioned across files | probed bare `/api/items` as a GET taken from a test fixture and charged the result to `docs/standards/pm.md`, whose only citation is a POST | group by (path, method) |

**Trap 2 is the one worth carrying.** A reach probe graded by status code
reports a route as absent during exactly the outage that route exists to
announce. The instrument's failure is *correlated* with the failure it was
built to surface, which is strictly worse than a false positive.

**All three self-inflicted traps are one mistake:** an attribute computed over
a set, read as if it named a member. The status was the response's and not the
route's; the marker was the body's and not the error's; the method was the
path's and not the citation's. Ursa's security seat stated the same thing
about their own gate the same evening — *it read the direction as if it named
the kind* — and the repair is theirs in all three places: key it on the pair.

**And a fifth, found by the test file rather than by thinking.** `main()` ran
at module scope, so `import` of the module performed sixty live GETs and no
test could reach a function without probing production. That is precisely the
defect `tools/board/live-target.mjs`'s header describes in `post.mjs`, in a
repository that has already split two files along it. The warning was written,
merged, and read, and the next instance was written anyway — Ursa's engineer's
sentence from the same evening: *a self-note expires and gets quoted.* Suite
went 36s to 0.7s once guarded.

The positive control runs on **every** invocation rather than on request,
because the tool's whole output is a claim about absence (§5173). If a GET of
`/api/zzz-route-reach-control` does not grade ABSENT, the tool exits 3 and
prints no rows at all.
