### What this run added

An audit of the inherited work found a defect in commit 5, in exactly
the class commit 5 exists to close. The new message tells the reader to
repair the checkout with `bash tools/ensure-full-clone.sh`, and that
command exits 127 from `ursa-major/`, which is the cwd an npm script
gives the reader. The script is at the repository root's `tools/`.

The existing test could not have caught it. It asserted
`toContain('bash tools/ensure-full-clone.sh')`, which compares the
message to a copy of itself. So the fix is the constant
`FULL_CLONE_REPAIR`, a new gate in
`src/regen-commands-runnable.test.ts` that resolves every command any
state of either function names against the cwd it is printed in, and
the two old assertions repointed at the constant.

Two prose instances of the same defect were fixed alongside it, in
`docs/design/clone-completeness.md` §6 and
`docs/design/counting-a-rename-once.md` §6.
