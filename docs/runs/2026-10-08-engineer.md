## The defect running it found

alone and asserted a cause on every zero: "no commit here carried an agent
marker that a later human commit then edited." Running the design doc's
own §4 recipe at the default `--min-chars` printed that sentence on a run
whose own step output said `units-found=1`. A commit did carry the marker;
the pair was found, resolved, and dropped by the size floor.

`unitsFound === 0` and otherwise reports the per-bound counts that
`src/ci/run.ts` tracks, carried on `RunCommentContext.dropped` rather than
in the five fields, because the fixed field order is what the surface
sells. A caller tracking nothing is told the run does not know.
