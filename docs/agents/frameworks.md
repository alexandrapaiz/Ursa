# Frameworks register — Ursa

Maintained by the PM seat (prompts/pm-agent.md §1e, docs/standards/pm.md
§7). The law: a framework must never consume more than the work it
organizes. Every framework considered enters here with the specific
problem it would solve, and a verdict: adopted-minimally, trialing, or
discarded-with-reason (the most common verdict by design). At most one
trial at a time. Every adopted practice lists its ceremony cost in
minutes per week and a review date on which it dies by default unless
it visibly paid for itself.

First version, opened 2026-09-21. This run's budget went to opening the
first sprint and the overlay PR/FAQ; active scanning of what other
companies publish about how they run starts next run. The one entry
below is a framework already load-bearing in Ursa's own standard, not a
result of that scan — it is here because it is real and in use, not as
a placeholder.

## Register

### Working Backwards (Amazon PR/FAQ) — adopted-minimally

- **Problem it solves here:** nothing stopped a large, product-shaping
  design (the overlay, product-plan.md §16) from drifting straight into
  a sprint as ordinary backlog items, sized and estimated before anyone
  had written down whether a customer would want it.
- **Verdict:** adopted-minimally, per the company standard
  (docs/standards/pm.md §2c, vendored from HQ ADR-019). Applied for the
  first time this run: docs/prfaq/overlay.md.
- **Ceremony cost:** one PR/FAQ document (roughly one page plus FAQ) per
  initiative larger than a sprint item, drafted by the PM, merged by the
  owner. Not a recurring meeting; cost is per-initiative, not
  per-week, so no minutes/week figure applies until the rate of
  large initiatives is known.
- **Review date:** 2026-12-31 (Q4 close). Check then whether any
  PR/FAQ changed a build decision (the rule's actual test, per
  docs/standards/pm.md §2c: "if the press release does not read as
  something a customer would want, the build does not start") or
  whether it only added paperwork around builds that would have
  happened anyway.
