What a run literally executes

# enumerate commits with author, date, and Co-Authored-By trailer

git -C <project> log --all --date=iso-strict --pretty=format:

  '%H%x09%an%x09%ae%x09%aI%x09%(trailers:key=Co-Authored-By,valueonly)%x09%s'

# files a commit touched · then the exact blob at that commit

git -C <project> show --name-only --format='' <sha>  ·  git -C <project> show <sha>:<path>

# the one model call, on your subscription, prompt on stdin

claude -p --model sonnet --output-format json

WHAT COUNTS AS A GENERATED COMMIT

Its Co-Authored-By trailer matches /Claude|Codex|Cursor|GPT/i — the trailer agent commits already carry today. An existing convention reused, not a new one invented.

WHAT PAIRS WITH IT

The next commit by author date touching an overlapping path, with no agent trailer, authored by git config user.email — that is you, editing what the agent wrote.
