RUNTIME · ADR-003

You launch it. It never watches.

No background process, no timers, no reading of chats. You select a finished project and launch a run. The software ships as one sealed, ready-to-run bundle; Ursa hands you the bundle and never runs it for you.

YOU RUN IT

ursa run, pointed at a project you finished. One command, one pass over its git history, then it exits. Nothing running before, nothing after.

YOUR GITHUB RUNS IT

Fires when a pull request merges, because your own workflow says so. Event-driven, in your account, on compute you control. Works with any coding agent.

LATER, IF YOU ASK

Scheduled runs and a remote endpoint (a small server any AI chat connects to, keyed to you) layer on top as opt-ins. Never the default.
