# Presentations

Slide sources for the decks, one folder per deck (deck.json is the
order and typography index; each slide is one HTML section on a
1920x1080 canvas). Live rendered versions are Claude artifacts owned by
Alexandra:

- forward-plan/ — Ursa Forward Plan (strategy: mission trio, n=1,
  taste pipeline, resolver v2, the clock, gates, end state).
- product-plan/ — Ursa Product Plan (internal: runtime, components,
  data flow, capture and delivery matrices, milestones with acceptance
  tests, sequence, capacity, decision queue).

Meeting notes live in docs/allhands/. The plan of record is
docs/design/product-plan.md; where a slide and the plan disagree, the
plan wins.
