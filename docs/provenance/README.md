# docs/provenance/

Derived indexes that turn an identifier a record carries into something a
reader can look up.

| File | What it answers | Built by |
|---|---|---|
| [`bundle-digests.md`](bundle-digests.md) | "A record says `resolvedBy: { basis: bundle_digest, digest: d325430704… }`. Which build of the resolver is that, and when?" | `ursa-major/tools/make-bundle-digest-index.ts`, from this repository's git history |
| [`bundle-digests.json`](bundle-digests.json) | the same rows, for a program rather than a person | the same script, same run |
| [`bundle-reproducibility.md`](bundle-reproducibility.md) | "Two people build one commit of the resolver. Do they get the same digest?" | written by hand, from `ursa-major/tools/measure-bundle-layouts.sh` |

The two index files are not hand-maintained. Each is regenerated by a script and
compared against the repository's history by `ursa-major/src/provenance-index.test.ts`,
so a stale index fails `npm test` rather than quietly disagreeing with
the history it claims to describe. How the index is built, and the one
rule it imposes on anyone who rebuilds the resolver, is in
[`docs/design/bundle-digest-index.md`](../design/bundle-digest-index.md).
