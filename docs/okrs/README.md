# OKRs

Owned by the OKR seat (prompts/okr-agent.md). One file per quarter,
named `YYYY-qN.md`; the newest file is the current quarter. Committed
only by the owner's merge; unmerged OKRs bind nobody.

## Quarter file format

```markdown
# OKRs YYYY-QN — <one-line theme naming the mission it serves>

## O1 — <objective, one sentence>

- KR1.1: <measurable result, with the number that makes it verifiable>
  — status: on-track | at-risk | missed | done
- KR1.2: ...

## O2 — ...

## Check-ins

### YYYY-MM (monthly)

- Benchmark: the five-axis scores against this month's three
  competitors, one sentence of evidence each, and what moved.
- KR scoring: every key result's status, each backed by a number or a
  diff.
- Drift audit: orphan work and orphan objectives, if any.
- Notes: dated sharpenings of KR wording or numbers; never new or
  dropped objectives mid-quarter.

## Retrospective (written at quarter close)

<final scoring, what the quarter proved, what carries>
```

Statuses only the evidence can set. At most three objectives per
quarter with at most three key results each, except where the owner has
committed otherwise (Q4 2026 carries four objectives by the walkthrough
of 2026-09-18).
