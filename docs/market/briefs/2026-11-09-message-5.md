   Partners/S32-led) at a $3.5B valuation, roughly triple its prior
   mark, reported as driven by "AI labs' insatiable appetite for
   high-end training data" rather than by any named deal. So what:
   beyond closing the last of the 18th run's four named leads (Appen
   and Sama still unchecked, iMerit still unchecked), this is the
   sharpest funding-scale demand signal this file has for the category
   since Mercor's and Handshake's own valuation jumps, and a reminder
   that a confident claim inside this file is not itself a substitute
   for the entry it describes — the same discipline this file applied
   to Memory Forge's traction claim last run, now applied to its own
   prior prose.
2. **A frontier lab's own privacy policy has an undisclosed carve-out
   on exactly the promise CLAUDE.md's non-negotiable #2 is built
   around, and this is the most concrete version of that gap this
   file has found in a Key Partner rather than a tracked competitor.**
   Anthropic told Claude users (deadline 2025-09-28) that opting out of
   training-data use would keep conversations out of future models.
   Its 2026-06-08 privacy policy update (effective 2026-07-07) added a
   clause: conversations flagged for safety review are used for
   training "regardless of a user's stated preference," with no
   disclosed trigger for what counts as flagged and no commitment to
   tell a user when it happens. So what: "the user can always see,
   edit, revoke, and delete what's been inferred about them, no dark
   patterns" is currently a general promise in CLAUDE.md. This is a
   dated, sourced, named instance of the market's most safety-focused
   lab failing to keep that exact promise cleanly — for a defensible
   reason, not a cynical one, which makes it a harder case to wave
   away. "What you revoke is actually gone, with no undisclosed
   exceptions" is a sharper and more checkable claim than "we respect
   your privacy." Ledger proposal below. Not a landscape.md entry:
   Anthropic is a Key Partner here (the platform Major runs on), not a
   tracked Category 1/2/3 rival.
3. **An independent, non-adversarial argument for Major's portability
   pitch surfaced the same week, from someone with no reason to be
   making Major's case.** A 2026 essay on why users don't switch AI
   models argues the lock-in is behavioral rather than technical: an
   endowment effect where "the more you prompt, the more entrenched
   your goals and aspirations become to the existing model," compounding
   into switching costs closer to re-explaining yourself to a new
   person than to changing software. Its framing of the winning
   dynamic, "which model knows the person better," is Major's value
   proposition in someone else's words. So what: read next to finding
   2, this is the positive half of the same week's evidence — one
   source shows what the market gets wrong about consent, the other
   shows why the thing Major restores (a portable self, not stuck
   inside one vendor's product) has value independent of privacy.
   Cited in positioning.md alongside finding 2, not as a separate
   section — same ceremony, same week, same reader.
