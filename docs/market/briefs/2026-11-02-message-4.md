## What this run found

1. **Four frontier labs just jointly shipped shared consent
   infrastructure, for a different asset than the one Minor sells, and
   the gap that leaves is sharper than it looks at first read.** Google,
   Microsoft, OpenAI, and Anthropic announced support on 2026-10-30 for
   a shared robots.txt token (`__usage_ai-training`), authored as an
   IETF draft by Anthropic's Kevin Kelley, letting a publisher state one
   preference against its content being used for AI training instead
   of maintaining per-lab opt-outs. So what: this is the first case this
   map has found of labs cooperating on neutral, standardized consent
   plumbing for any data asset, which is a real precedent. But it is
   opt-out only, not consent-based, scoped to training and not
   grounding, and silent on a user's own interaction or preference data.
   It answers a different question than CLAUDE.md §0's non-negotiables
   (portable ownership, full visibility and revocation of what's
   inferred about a person). The standing gap this file tracks isn't
   narrowed by this, it's sharpened: labs will build shared consent

   including this standard's own sponsors, has built the user-level
   equivalent yet. Added to positioning.md. Source:
