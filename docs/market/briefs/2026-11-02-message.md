## What this run found

1. **The market's closest-yet attempt at sourcing real (not
   constructed) work is reported two incompatible ways, and either
   way it carries a liability Minor's design doesn't.** TechCrunch
   (2026-01-10, found this run) reports OpenAI and Handshake AI asking
   contractors to upload actual files from their real past and current
   jobs — "not a summary of the file, but the actual file." A separate
   report (bespacific.com, syndicating a longer piece) names the same
   relationship "Project Stagecraft" and describes a different
   deliverable: 3,000-4,000 contractors paid $50-500/hr across 400+
   occupations, "directed to develop a persona and create tasks that
   reflect real work" — an authored simulation, not an uploaded file.
   So what: this run could not resolve which account is accurate, and
   recorded the conflict rather than picking a side. Under either
   reading it doesn't close Minor's gap (real data with no
   provenance, or a constructed task with a new name), but a third,
   separately-confirmed fact does something sharper: an IP lawyer
   quoted by TechCrunch warns the approach puts the lab "at great
   risk," since it trusts each contractor to judge what from a former
   employer's work is safe to share. Minor's own signal comes from a
   user's own real work, under that user's own consent — a
   confidentiality liability this market's own closest attempt at
   "real" data is now visibly carrying, and Minor's isn't, by
   construction. Ledger proposal below. Separately, contractors on the
   same OpenAI projects report Handshake withholding "thousands of
   dollars" in pay (AOL/Business Insider, 2026-03-04) — the same
   labor-conditions pattern this file already tracks for Mercor.
2. **A venture investor independently named the same line this file
   has drawn for two months, calling it "Type 1 vs Type 2."** Deedy
   Das, a Menlo Ventures partner, published an industry landscape map
   (reported via BigGo Finance) defining "Type 2" data as tasks
   designed by humans and completed by experts — this file's entire
   Category 1 — and "Type 1" as data captured directly from real
   business operations, arguing Type 1's marginal value is rising
   because models have already learned to "solve exam problems" and
   now need to learn how work actually happens. The report calls
   GitHub "the world's largest Type 1 data repository" and credits it
   with coding's fastest capability gains — an investor's version of
   CLAUDE.md §1's own argument, for domains with no Type 1 corpus yet.
   So what: this is citable, non-Minor-sourced corroboration for
   KR4.1's lab brief, but every company the report names as an early
   Type 1 play (Handshake, Protege, Sunset, SF Data) still stops at
   real data, short of provenance, when checked directly — see finding
   1 and the new Protege landscape entry. The brief's sharper line is
   "every funded attempt at Type 1 so far stops at bulk real data;
   none joins it backward to a generation," not "a VC agrees real
   data matters."
3. **A second voluntary lab-cooperation standard, four days old at
   this run, moves closer to the consent layer than the first one
   did, and still falls short of Major's own promise.** OpenAI,
   Google, Microsoft, and Anthropic agreed (draft dated 2026-10-30,
   authored by Anthropic) to a shared robots.txt token letting any
   publisher opt out of AI training across all four crawlers with one
   line. This is the sharper half of the "labs won't cooperate on
   consent" question the 2026-10-26 entry already revised once for
   agent infrastructure (AAIF). It still doesn't touch Major's layer
   (publisher content, not a user's personal profile), and it is
   explicitly weaker than CLAUDE.md §0's own promise: it can't
   retroactively revoke content already used in training and "carries
   no binding enforcement power," where Major's own non-negotiable is
   revoke-and-delete, not just stop-using-tomorrow.

## The gap

The market's own closest attempt at "real" work data this run
(Handshake/OpenAI, whichever account is accurate) still collects
either a provenance-free file or an authored simulation, never a
record of what an AI generated and what of that generation survived
contact with a real deliverable. The sharper new fact this week isn't
that the gap persists; it's that the market's own closest attempt at
closing it is now visibly carrying a confidentiality liability Minor's
design doesn't have, and an investor has independently priced the
underlying shift ("Type 1 data") as worth funding, without anyone
named in that shift yet building the thing CLAUDE.md §1 describes.
