## What this run found

1. **A second, independent "software is not the moat" case landed
   this run, and it is a solo open-source project rather than a
   frontier lab's own release.** MemTether (new Category 3 entry,
   docs/market/landscape.md), a free, Apache-2.0, forked solo project
   with no company or funding behind it, ships bi-temporal
   correction-supersedes-overwrite memory, a hash-chained audit log,
   and a human-adjudicated conflict gate for AI coding tools sharing
   one local SQLite file. That governance model is the closest
   open-source analog yet found to CLAUDE.md §1's own span
   classification and trajectory idea, closer than the better-resourced
   MemHub (2026-10-24). Run through the same head-start-vs-position
   test the MemHub entry built: both criteria fail (no aggregation
   layer, no lab relationship), so this costs Ursa the head start, not
   the position, same conclusion as MemHub. What's sharper is that two
   unrelated actors with zero connection to each other or to Ursa —
   a frontier lab's open-source division and an anonymous solo
   developer — have now converged on adjacent pieces of the same data
   structure independently, which is stronger corroboration of "anyone
   competent could build it" than one example supports. Full positioning
   consequence in docs/market/positioning.md.
2. **The category's largest-by-adoption memory product shipped a real
   cross-tenant memory leak, not a hypothetical one.** CVE-2026-116575
   (published 2026-10-26, CVSS 6.3, patched in Mem0's Python SDK 2.0.18
   and TypeScript SDK 3.1.6) found that Mem0's session-scoping code
   joined caller-controlled `user_id`/`agent_id`/`run_id` values with
   unescaped delimiters, letting a crafted identifier collide with a
   different tenant's session key and read or write that tenant's
   memory. So what: this extends the "trust has a provenance axis too"
   line (2026-10-07) one level deeper than any case tracked so far —
   the compromise sits inside the memory product's own multi-tenant
   isolation code, not at the vendor-ownership or supply-chain level
   the earlier Scale AI and Mercor cases tracked. It is a dated
   instance of a risk category Major's on-device processing (CLAUDE.md
   §0, constraint 3) does not carry by construction: there is no
   shared tenant boundary to collide across when raw processing never
   leaves the device.
3. **A weak but concrete demand signal priced the exact promise Major
   makes, named as weak rather than dropped.** A Show HN post this
   week ("AI Context Flow," 1 point, 4 comments) pitched a browser
   extension carrying context between ChatGPT, Claude, Grok, Gemini,
   and Perplexity at $12/month after a free beta. Engagement this thin
   is not market validation, but it is a dated price point for
   cross-model memory portability sitting inside this file's existing
   price ladder, closer to Zep's post-restructure $25/mo Flex tier than
   to any enterprise contract. Held as one low-confidence data point,
   not cited as a trend.

## Report for the owner

This week's clearest market fact: a second, completely independent
party — an anonymous solo open-source developer, with no funding and
no connection to Tencent's earlier MemHub release — has now built an
adjacent piece of the same data structure CLAUDE.md §1 describes
(corrections that supersede rather than overwrite, with a verifiable
audit trail), for free, for a narrower problem than Major solves. That
is not new in kind — the charter's own non-negotiable about software
never being the moat already said this would happen — but it is the
second independent proof of it inside two weeks, which argues the rate
this is happening is itself worth watching, not just the fact that it
happens. Separately, the market's largest memory product by adoption
had a real cross-tenant data leak this month, which is a concrete,
dated argument for the provenance-trust story rather than a
hypothetical one. Nothing here argues for a pricing or positioning
decision only you can make today; the open decision this seat has
flagged in prior runs (whether Minor commits publicly to a
no-dual-sale, single-buyer-tier data-provenance guarantee before
KR4.1's brief is drafted) is still open and still yours.
