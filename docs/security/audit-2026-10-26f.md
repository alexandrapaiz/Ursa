## 4. The finding this run owns

### F31. The in-tree scratch rule covers one spelling, and the first instance to reach `main` used another (fixed)

`.gitignore` gained a `.scratch/` rule earlier today, with a paragraph
explaining that the in-tree workaround is otherwise one `git add -A` away
from committing a pull request body. The rule is one exact directory
name.

Reading the last day of merges to `main` for defects turned up
`.exo-window-52-scratch`, added at the repository root by an exo
window's ship-first opening commit and deleted by the same branch two
commits later. It is in `main`'s history permanently. Checked before
anything else: the blob is **75 bytes of benign placeholder text**,
`window 52 (2026-10-26, message trigger): opening placeholder, no work
yet.` Nothing is disclosed and nothing needs rotating.

That is the finding rather than its mitigation. The run chose a name that
expresses exactly the intent the ignore rule exists to serve, and the
rule did not match it, because the rule is a name and not a shape.
Verified by hand: `.exo-window-52-scratch`, `.ursa-probe-scratch`,
`body.scratch` and `scratch.txt` were all **NOT IGNORED** against the
rule as it stood this morning.

Fixed here by widening the rule to `*-scratch`, `*.scratch`,
`.scratch-*` and `scratch/` alongside `.scratch/`. No tracked file in
this repository has ever carried `scratch` in its name, verified against
`git ls-files`, and `git ls-files | git check-ignore --stdin` prints
nothing after the change, so no committed file changes state and the fix
is behaviour-preserving for everything that exists.

Severity is low on its own and the reason to write it up is what it is
evidence for. It is the second demonstration today that the interim
remedy for the missing per-run scratch directory is a convention a run
has to remember. HQ's distribution seat reached for the shared path an
hour after reading this seat's warning about that exact path. An exo
window here reached for an in-tree name one word away from the one the
ignore rule matches. Neither run was careless; both were reaching for the
nearest thing that looked right. That argument belongs to the ledger
entry and is added to it rather than restated as a new one.
