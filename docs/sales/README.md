# docs/sales/ — the sales seat's working surface

First run: 2026-09-30 (owner window dispatch). The sales charter
(`prompts/sales-agent.md`) is still marked DORMANT and still written for
alexandria, a paid newsletter. Ursa is not that business. This directory
is the seat's adaptation, built in the open so the owner can accept,
edit, or reject it.

What lives here, once this run lands:

| File | What it is |
|---|---|
| `adaptation.md` | What "sales" means at Ursa, and why the alexandria charter does not transfer line-for-line |
| `calendar.md` | The campaign calendar, keyed to the M0→M2 runway, not to a launch date we do not have |
| `campaigns/` | One folder per campaign, each holding ready-to-send drafts |
| `outreach/` | Named people and venues from public surfaces only, each with evidence of fit and a drafted note |
| `results.md` | What the owner actually sent, and what came back |

Two laws hold over everything in here, and neither is mine to change:
**the owner sends, I only prepare** — no posting, no DMs, no email, no
accounts — and **every claim is true today**, sourced to a file in this
repo or a public page, never to a roadmap.
