   (engineer) — serves O1 KR1.2, the quarter's named autonomy KR.

   not only chat" (2026-09-20, accepted). Done means: `OutcomeRecord`
   gains `artifact: { kind: 'chat' | 'repo' | 'hosted' | 'visual',
