# skills/

Ursa's skill library. Each skill is a directory holding a `SKILL.md`
whose frontmatter carries version, status, provenance, and validation
state, and whose body carries procedure plus judgment.

Ursa's skill seat produces one skill per run. The provenance rule is
the same one the parent company's library runs on: every claim-backed
sentence cites its source, and practical judgment that no source backs
is marked as ours rather than dressed up as evidence.

This run is in progress. See the open pull request for what it adds.
